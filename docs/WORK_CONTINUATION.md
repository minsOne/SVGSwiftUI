## 구현 중 준수 규칙
- 파서/모델 계층은 UI 타입(`Color`) 의존을 피하고 값 타입 중심으로 유지
- override 우선순위는 항상 `원본 < map < resolver`
- 캐시 키는 입력 + 파서 옵션 + 스키마 버전을 모두 포함
- 미지원 SVG 기능은 크래시 없이 무시하고 진단 로그 남김
